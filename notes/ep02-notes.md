# 第二話討論筆記

## 上接第一話的決議

- **B從第二話起不再進校**。K只從旁人口中得知B「怕上學」，聯絡過但B不回應。
  這條線到此為止，只留一句「他失去了一個朋友」的餘味，不再糾纏誤會細節。
  → 建議B的淡出用一個**具體物件**帶過（例如K傳的訊息停在未讀/已讀不回），
  不要用抽象敘述句直接告知讀者。
- **核心決定**：這個劇本要陳述的是「創傷本身」，不是人際關係的糾纏過程。
  共鳴感要靠筆觸的準度撐起來，不是靠劇情堆疊解釋。
- **K的核心病灶**（跨話貫穿）：話永遠慢一拍、來不及在關鍵時刻說出口。
  失去B、（可能）失去A的瞬間，都敗在同一件事——這是系列的骨架，不要在
  單話裡解釋破，要讓讀者自己在多話之後拼出來。

## 第二話開場結構（已定案）

1. **現實教室**：B的座位空著，同學低語議論。K只是看著空位。
   （B的缺席只用畫面帶，不解釋。）
2. **回到灰域**：K、A兩人正往回走（試膽路線的返程）。閒聊，K關心一下。
3. **K鼓起勇氣想稱讚A**（不到告白，克制、可否認的稱讚）。
4. **A追問「為什麼？」**——A個性大方直接，逼K多走一步、講出更接近真心的話。
   這是A的性格在推劇情，不是作者硬拗。
5. **切斷手法**：先讓K（和讀者）察覺「安靜」——腳步聲、呼吸聲先消失，
   K才回頭發現A不在了。不要用「一轉頭剛好」的巧合式切法。
6. **那句稱讚的關鍵字永遠不會說出口**——呼應K「話卡在第三句」的病，
   讀者和A一樣，永遠不知道那個形容詞是什麼。

### 對話草案（已收斂的版本）

```
「……還好是跟你一組。」
「嗯？為什麼？」她的語氣很輕，是真的在問，不是客套。
「A，其實我……」耳朵燙起來。他盯著鞋尖，「我覺得，你……」
那個字卡在舌頭後面。
——沒有聲音了。
剛才還在的呼吸聲、腳步聲，全都沒了。
他回頭。
A不在。
```

可選的收尾餘味：K維持半轉身、嘴還張著、那個字還含在嘴裡的姿勢愣住一兩秒——
那句話就這樣永遠停在他嘴邊。呼應第一話「手抬起半公分又放回去」的動作語彙。

## 第二話創傷主軸：謊言（已定調）

- **設定**：K數學還可以（呼應第一話他知道應用題答案），但地理／歷史不行。
- **事件**：K拿到一張27分的考卷，被老師當眾嘲諷，同學訕笑。

### 壓力源的真正核心（重要）

- 謊言只是表層。底層壓力源不是「怕被拆穿」，是**逃避情緒勞動／情緒暴露**。
  K說謊不是為了躲懲罰，是為了不必承接媽媽的失望與擔憂、以及自己「被看穿」
  的無地自容。
- **這和第一話是同一個病灶**：K無法忍受「在另一個人面前情緒暴露的那一刻」。
  對B（不敢舉手）、對A（話說不完）、對媽媽（不敢說實話）——都是同一個病。
- 第二層壓力源：**維持謊言本身的慢性消耗**（要記得說過什麼、隔絕感、
  每天懸著的低頻恐懼）。這一層直接接到灰域怪物的機制（見下）。
- 情感顏色：**羞恥**（27分被公開）×**被比較的壓力**（哥哥）×**說謊的疲憊**，
  三者絞在同一張餐桌上。不是「愧疚」（那是第一話），這一話是「羞恥」。

### 媽媽這個角色（已定調）

- **不是易怒虎媽，是有教養、卻高壓的溫柔型**。她會說「對的話」
  （「媽不是要跟你比」「你盡力就好」），但壓力從她說話時沒在看K、
  從話裡的縫隙漏出來。
- 越是溫柔的失望，K越沒有出口——被罵還能反抗，面對安靜的失望只剩「我是罪人」。
- 這樣K的謊言才是**對愛的背叛**（結構同第一話「背叛好友」），壓力才夠重。

### 餐桌場景（寫實設定 + 草案）

- **寫實化**：台灣雙薪家庭，媽媽下班買**便當**當晚餐；**水果是現切的**。
  今晚爸爸晚歸、哥哥已上大學不在——**只剩K和媽媽，沒有緩衝、無處可躲**。
- 時機：飯後、水果、獨處——一天中最放鬆家常的時刻，刀就在這裡捅進來。
- **謊言用「剛好及格」**，不是謊報高分。他不敢奢望「好」，只求「不是災難」——
  連他的謊都是平庸的。而媽媽對這個謊的回應仍是「也該上緊一點了」——
  **他連在謊言裡都不及格**。這是本場的情感引擎。
- 水果=愛的動作（削、推到他面前），媽媽一邊做這個動作一邊比較他——
  K同一口吞下關愛和傷害。他忍著眼淚吃水果＝用咀嚼把眼淚嚥下去。
- 餘味空鏡：媽媽收拾進廚房、水聲響起，K獨自坐著，面前剩一塊沒吃、
  已氧化變褐的水果——那是他吞不下去的那部分真相。不點破。

對話草案：
```
餐桌上只剩他和媽媽。爸爸還沒回來，哥哥回學校了。
媽媽端了一盤蘋果過來，切好的，擺成一圈。她把靠近K的那幾塊往他面前推了推。
「今天不是有考試？」她坐下來，「考得怎麼樣？」
K的叉子停了一下。
（二十七。）
「……還好。」他叉起一塊蘋果，「剛好及格。」
「及格喔。」媽媽也拿了一塊，慢慢削著邊上沒削乾淨的皮，語氣很平，「……也該上緊一點了。」
K「嗯」了一聲。
「你哥你這個年紀的時候，」她還低頭看著那塊蘋果，不是在看他，「每次都前三名。也沒補習。」
她說得很輕，像在講一件跟誰都無關的事實。
「媽不是要跟你比。」她把最後一塊也推到他這邊，「你盡力就好。」
K盯著盤子裡那圈蘋果，一塊一塊，排得很整齊。他又叉起一塊，塞進嘴裡，用力嚼。
只要嘴裡有東西，他就不用說話，臉也可以裝作是在忙別的。
眼睛有點熱。他多嚼了幾下，把那個熱度也一起嚥下去。
「……好。」
```

## 灰域怪物機制（已定調）

- 怪物先用A的聲音當餌（「在這裡，我剛滑了一下」），K以為是A、關心地走近。
- 轉角出現的不是A：身形有點像，但黑色軀體、飄散紫色霧氣。
- 怪物台詞呼應開頭沒說完的稱讚：「你覺得……我……怎麼樣？」
- **機制三段**：
  1. **謊言（輕描淡寫）＝餵養怪物**。K越靠近越沒力——維持謊言＝消耗。
     怪物不是靠攻擊逼近，是K自己餵大的。第一話的「喊願望→給實體物件」
     解法在這裡**故意失效**：K喊「擋住牠」，天花板掉水泥，但霧氣穿過去。
     ——你不能用牆擋住一個謊言。
  2. **真話（壓抑的情緒）＝鬆動它**。怪物說出K的謊（安撫詞），
     K喊出被壓在底下的真話。**對喊要一句一句交錯、從對外防衛升到對內崩潰**：
     ```
     「你不過如此。」        →「我想做得更好！」
     「比起別人……」        →「我不想再被比了！」
     「還好。」（放很輕，像哄他）→「一點都不好！」
     「及格邊緣。」          →「我完全搞砸了！」
     「別擔心。」            →「我擔心死了——！」
                            →「不要再過來了！」
     ```
     ——不需要具體的「27分」。具體的是數字，普世的是情緒。換成情緒，
     每個讀者都在裡面看到自己。「還好」是K的口頭禪（第一話對A也說「還好」），
     這裡等於清算他整個人的口頭禪。
  3. **自我體諒（那口吐氣）＝吹散它**。關鍵：**觸發的那句音量要往下掉，
     不是往上**。用「更大聲的喊」解決會變以暴制暴，主題就歪了。
     真正壓垮「假裝沒事」的，是K終於不再罵自己、承認自己累了：
     首選觸發句 →「……我已經，很努力了啊。」（音量小、抖）
     那一瞬間他不再餵怪物。
- **破窗＝吐氣**：一陣強風吹破玻璃、窗簾飛起，怪物瞬間失去形體、被吹散。
  碎片劃傷K的臉頰與衣物（凌亂，但都是小傷）。風漸轉夏日暖風、帶花香，然後消失。
- **小傷的回收（弧線進一步）**：呼應第一話「傷大多是自己造成的」，但意義反轉——
  第一話的傷是「逃避／恐懼」造成的（自我傷害）；這一話的傷是「那個救了他的
  東西（破窗的風）」造成的（突破）。同一個motif，弧線進了一步。可讓K摸到臉上
  的血愣一下——這次他大概說不出「還好」了。

## 穿插結構（已定調）——與第一話同一建築

峰值無助 → 切回現實解碼 → 回來收尾（第一話：追逐峰值→教室閃回→回灰域面對）。

1. **教室**（B缺席）— 冷開場、氣氛、失去朋友的餘味
2. **灰域**（往回走 → 稱讚A說不完 → A消失）
3. **灰域**（尋找A → 假A的餌 → 怪物現形「你覺得我怎麼樣」→ 撲近、抽乾、
   擋牆失效 → K大叫，最無助）
4. **餐桌**（便當+現切水果 → 比較 → 那些謊 → 忍淚）← 在此插入，解碼怪物
5. **灰域**（回到現場：對喊 → 吼出真話 → 「我已經很努力了」→ 破窗、暖風、
   怪物散、小傷）
6. **灰域**（A回來 → 餘味）

### 兩座「橋」讓剪接不突兀（第一話用「啪」聲當橋）

- **切進去（灰域→餐桌）：用「喉嚨」當橋**。灰域怪物霧氣掐住胸口、K喊不出來
  （喉嚨緊、吞不下）；硬切餐桌，K「喉嚨緊緊的，吞下去有點痛」。同一身體感覺
  跨過剪接。
- **切回來（餐桌→灰域）：用「謊言的詞」當橋**。餐桌收在「還好」，硬切回灰域，
  怪物第一句就是「還好。」剪接點本身就是揭露。

### 貫穿線：喉嚨（吞→掐→吐）

- 餐桌：**吞**（壓抑）——吞淚、吞真話、吞「還好」
- 灰域：**掐**（窒息）——怪物掐喉，喊不出真的東西
- 結尾：**吐**（釋放）——吹破玻璃的那口風＝終於不再吞、吐出來的氣
- 不點破，但每段摸一下喉嚨這個點，整話會有一條看不見的筋。
