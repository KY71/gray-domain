## 每一輪改了什麼

**Round 1（原稿 → 第二稿）** — 把設定「藏得更好」、對白更像慌張的高中生：
- 怪物分三段漏「腦」字，與 K 記憶浮現同步。
- A 從「工具人」變成知情的旁觀者（數學課上她看的是 K 縮回去的那隻手），結尾用「跟那天一樣，他沒有回頭」收束。
- 拿掉鄉民抱怨的結尾「臉紅微甜」情緒斷層；破音、髒話口頭禪讓兩個高中生活過來。

**Round 2（第二稿 → 第三稿）** — 兩位文學評審一致診斷：**改過頭了，把潛台詞翻成了明說**。於是大量「刪」：
- 砍掉四處主題明講的「解釋性尾巴」，只留硬意象（舌尖／那隻手／啪＝講桌／埋臉背影）。
- 自傷從「事後招供」改成「當下身體」＋讓 A 的「不碰」去承接。
- 追逐壓到兩拍（積水移植到斷樓梯斷口）；讓怪物哭得像 B 成為結尾收束音，而非加害話語。
- 鐵管改成詭異地「早就在那裡」，取代「滾到腳邊」的都合主義。

**Round 3（第三稿 → 定稿）** — 三稿已無硬傷，做最後定調：
- **殺招去俐落化**（心理評審唯一「一定要改」）：把「又快又狠正中頸側」改成閉眼亂揮、失衡、幾乎意外掃中——避免全篇最後半秒滑回「打贏惡霸」的自我開脫。
- 修掉鄉民抓到的物理 bug：「鐵管邊緣削過自己手背」不合人體工學，改成怪物力道把鐵管連手一起砸回牆上。
- 前五段補一根極輕的懸念刺（想不起怎麼進來，隨即被暗戀蓋過）。
- 結尾補回半拍共同凝視；緩解「卡在喉嚨」母題的重複。

## 一個觀察

三位評審的分歧本身就是產物：兩位文學評審把作品往「更克制、更信任讀者」推（刪解釋），輕小說鄉民則要「更快、更爽、主角更有主動性」（那是連載向的商業節奏）。定稿選擇以兩位文學評審為主軸（此篇的文體與意圖是文學向心理懸疑），同時吸收鄉民在**工藝層**的具體命中（都合主義的道具、人體工學 bug、情緒斷層）——這些不分文體都成立。鄉民要的「代價機制、K 的主動性、A 與 K 撕破臉」則留給後續話數，而非在第一話違背人物。
